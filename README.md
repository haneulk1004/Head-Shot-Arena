# 🔫 Head-Shot Arena

**Head-Shot Arena**는 HTML5와 Three.js로 제작된 **3D 웹 기반 서바이벌 슈팅 게임**입니다.
끊임없이 몰려오는 적들을 물리치고, 레벨업을 통해 무기를 강화하여 보스 **'INFERNO REACTOR'**를 격파하세요!

## ✨ 주요 특징 (Features)

### 1. ⚔️ 다양한 무기 시스템
상황에 맞춰 4가지 무기를 전략적으로 교체하세요.
* **🗡️ Saber (1번):** 근접 공격용 광선검
* **🔫 Pistol (2번):** 기본 권총 (밸런스형)
* **🔥 Rifle (3번):** 빠른 연사 속도의 소총
* **💣 Mecha Skull (4번):** 강력한 폭발 데미지를 주는 투척형 해골 폭탄

### 2. 🤖 다양한 적과 보스 레이드
* **Normal:** 일반적인 속도와 체력을 가진 적
* **Fast:** 체력은 낮지만 빠르게 접근하는 적
* **Melee:** 체력이 높고 덩치가 큰 근접 탱커
* **Healer:** 동료를 치유하는 지원형 드론
* **💀 BOSS - Inferno Reactor:** * 거대한 체력과 미사일/레이저 패턴 보유
    * 체력이 50% 이하로 떨어지면 **'TITAN MODE'**로 폭주하며 패턴 변화

### 3. 🆙 성장 시스템 (Roguelike Elements)
적을 처치하고 경험치를 모아 레벨업하세요. 매 레벨마다 랜덤한 업그레이드를 선택할 수 있습니다.
* **공격력 / 연사 속도 / 이동 속도 증가**
* **멀티샷 (Multishot):** 한 번에 여러 발 발사
* **무기 스킨:** 골드, 네온, 플라즈마 등 특수 스킨 잠금 해제

### 4. 📱 크로스 플랫폼 지원
* **PC:** 키보드(WASD) + 마우스 조작
* **Mobile:** 가상 조이스틱(이동) + 터치(사격) 지원

## 🕹️ 조작 방법 (Controls)

| 동작 | PC (키보드) | Mobile (터치) |
| :--- | :--- | :--- |
| **이동** | `W`, `A`, `S`, `D` | 화면 왼쪽 드래그 (가상 조이스틱) |
| **공격** | 자동 조준 / 클릭 | 화면 오른쪽 터치 |
| **무기 교체** | 숫자키 `1`, `2`, `3`, `4` | 화면 상단 무기 아이콘 터치 |

## 🛠️ 기술 스택 (Tech Stack)
* **Core:** HTML5, CSS3, JavaScript (ES6+)
* **3D Engine:** [Three.js](https://threejs.org/) (CDN)
* **Effect:** Custom Particle System, Shader Materials

## 🚀 설치 및 실행 (Local Run)
이 게임은 단일 HTML 파일로 구성되어 있어 실행이 매우 간편합니다.

1.  이 저장소를 클론합니다.
    ```bash
    git clone [https://github.com/YourID/Head-Shot-Arena.git](https://github.com/YourID/Head-Shot-Arena.git)
    ```
2.  `index.html` 파일을 더블 클릭하거나 브라우저로 엽니다.
3.  게임 시작!
